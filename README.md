# NEVE-GRID-v1.0
NEVE-GRID v1.0 adalah platform simulasi siber taktis adaptif untuk PUSSIBERAD (Kartika Cyber Hackathon 2026). Menggabungkan gamifikasi CTF, telemetri keterampilan real-time, dan mesin AI adaptif prosedural untuk mendeteksi skill gap prajurit serta men-generate skenario latihan secara dinamis.
